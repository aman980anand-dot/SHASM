SHASM (Safe Passive Web Security Scanner) is a Python and Flask-based web security scanning tool designed to identify potential security weaknesses in websites through safe, passive analysis. 
It examines HTTP response headers, cookies, HTTPS configuration, and other security-related information to detect missing security protections and configuration issues. 
The scanner provides evidence-based findings, severity levels, confidence ratings, and remediation suggestions to help developers understand and improve website security without performing intrusive attacks or exploiting vulnerabilities.
Main objective: To make website security assessment safer, simpler, and more understandable through automated scanning and clear security reports.
